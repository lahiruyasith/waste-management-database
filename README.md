# Waste Management Database

MySQL database for the Waste Management Pickup Scheduling and Route Planning System.

## Technologies
- MySQL
- MySQL Workbench

## Database Name
`waste_management_db`

## Database Tables
- users
- drivers
- vehicles
- waste_types
- pickup_requests
- schedules
- routes
- route_stops
- route_plans
- audit_logs

## Database Setup
1. Install MySQL Server.
2. Open MySQL Workbench.
3. Open and execute `schema.sql` on a new, empty database setup.
4. Configure the backend database connection in its local `.env` file.
